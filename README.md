# 리페어북 RepairBook — 웹사이트 MVP

사업계획서(고도화 2차본)의 서비스 흐름을 그대로 동작하게 만든 PC·모바일 겸용 웹사이트.

## 화면 (사업계획서 2-5 와이어프레임 기준)

| 주소 | 화면 | 계획서 |
|---|---|---|
| `#/` | 홈 · 증상/모델 진입, 이용 순서, 차별점, 지원 모델표, FAQ | W1 |
| `#/diagnose` | 증상 6종 → 모델 코드 → 자가 점검 → 사진 업로드 | A0 |
| `#/upgrade` | 업그레이드 진단 (SSD·RAM·서멀 구리스) — 모델별 가능/불가와 근거 | 추가 |
| `#/diagnosis/:id` | 진단 카드 (A 키트 / B 무료 가이드 / C 수리점) | W2 |
| `#/models`, `#/model/:id` | 호환 결과, 상세 사양·근거, 보증 고지, 따라오는 구매 박스 | W2 |
| `#/order/:id` | 구성 선택, 모델 코드 재확인, 동의 3종, 시세·패키지 분리 요약 | W3 |
| `#/guide/:id` | 7단계 가이드, 확인 체크, 중단 기준 고정, 원격 지원 | W4 |
| `#/orders` | 주문·배송 단계, 지원 내역 | A5 |
| `#/kit` | 키트 9종, 가격 비교, 오진 안심 보장표 | 2-4, 2-7 |
| `#/admin` | KPI, 호환성 DB 편집(자동 판정), 진단 승인, 주문 단계, 모델 요청 순위, 설정 | W5 |

규칙: 결제 게이트(A 판정 + 승인된 진단 + 모델 가능), 판정 자동화(빈 슬롯 ≥1 + 검수 완료 = 가능),
가격 = 설치 패키지 39,000원 + 부품(매입가 × 1.1), LG 그램은 제조사 테스트 최대 1TB까지만 판매.

## 실행

빌드 없이 바로 열리는 정적 사이트. 폴더에서:

```bash
python3 -m http.server 4173
```

→ http://localhost:4173

## 현재 한계 (데모)

- 데이터는 각 방문자의 브라우저(localStorage)에 저장됨 → 운영자 화면은 같은 브라우저의 데이터만 보임
- 결제는 실제로 일어나지 않음(PG 미연동), 카카오톡 채널 주소는 운영자 › 설정에서 입력
- 진단 자동 승인이 데모용으로 켜져 있음(운영자 › 설정에서 끄면 사람이 승인해야 결제 가능)
- 그램북 AI 2026은 모델 코드 미확정이라 ‘준비 중’
- 사진은 Unsplash, 가이드 영상(4개 단계)은 Pexels 무료 라이선스 자료(`assets/data.js`의 `RB_PHOTO`, `RB_VIDEO`) — 실물 키트·분해 사진과 영상을 찍으면 그 표만 교체
